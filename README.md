# Detecção de Fraude em Cartões de Crédito com Machine Learning

Este projeto desenvolve um modelo preditivo baseado em inteligência artificial para identificar transações fraudulentas em operações de cartão de crédito, aplicando conceitos de Ciência de Dados à Prevenção de Riscos em Fintechs.

## 💼 Contexto de Negócio
Em uma operação real de meios de pagamento, o desafio analítico consiste em mitigar o prejuízo financeiro causado por fraudes (chargebacks) sem gerar atrito ou falsos positivos na jornada dos clientes legítimos.

## 🛠️ Tecnologias Utilizadas
* **Python** (Linguagem principal)
* **Pandas** (Manipulação e tratamento dos dados)
* **Scikit-Learn** (Criação e treinamento do modelo de IA)
* **Regressão Logística** (Algoritmo de classificação binária utilizado)

## 📊 Resultados Obtidos (Métricas de Performance)
Após o treinamento com dados históricos e validação em uma base de testes inédita, o modelo apresentou os seguintes resultados operacionais:

* **Mitigação de Riscos (Recall de 64%):** Retenção automática de 64,3% das fraudes reais.
* **Eficiência e Baixo Atrito (Precision de 83%):** De quase 57 mil transações válidas analisadas, o sistema gerou **apenas 13 falsos positivos**, protegendo a experiência do cliente bom e evitando sobrecarga na mesa de análise humana.
